# Car Manager Research

Отдельный тестовый репозиторий для исследования и проверки **Car Manager (카매니저)**.

Официальное описание приложения указывает, что оно предназначено для дилеров подержанных автомобилей и поддерживает поиск объявлений по региону, производителю, типу автомобиля и дилеру, а также детальные фильтры вроде года и цены. citeturn0search0

## Цель

Пока не переносим и не меняем логику `encore`.

Этот репозиторий используется отдельно для:
- проверки доступности публичных ресурсов;
- исследования HTTP/API поведения;
- последующего анализа мобильного приложения;
- тестов интеграции.

На первом этапе **не обходим авторизацию и не обращаемся к приватным данным дилеров**.

## Первый тест

Требуется Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m src.probe
```

Можно указать другой адрес сайта:

```bash
CAR_MANAGER_URL=https://www.carmanager.co.kr python -m src.probe
```
